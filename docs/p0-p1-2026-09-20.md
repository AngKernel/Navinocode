## 数据边界

业务网站仍在唯一工作区记录中，移动/导入通过现有 store 的一次状态提交完成。
跨工作区移动给目标实体分配新 ID，并记录源实体删除标记，避免移动回原场景时被旧 tombstone 删除。
跳过的重复网址不删除源端实体。归档恢复、同步替换仍会重新生成实体 ID，并保留当前数据的删除标记。

`recoveryHistory.js` 只保存工作区快照；不包含 Supabase 凭据、原始书签树或会话。最多保留 20 个，合计 4 MiB。
超过数量/容量时裁剪最旧记录；浏览器剩余空间不足时进一步减少旧记录。新恢复点无法落盘则阻止后续覆盖。
旧 `navinocode_workspace_recovery` 在新历史不存在时读取，迁移后以新历史为准，不会在清空历史后复活。
损坏历史可导出原文，不静默重置。恢复确认同时校验预览后本地数据是否变化。

`browserSessions.js` 是独立的**本地辅助数据**，不与工作区或云同步混用。最大 20 个会话、每个 250 页、总共 1 MiB；容量不足不静默删掉已有会话。
仅保存普通窗口 HTTP(S) 网页；排除带 URL 账号密码的地址与内部页面，不保存隐私窗口。
恢复只操作这次新建的标签页，默认精确 URL 去重（主机名规范化，但路径/查询保留大小写）；预览确认后再核对当前已打开页面。
关闭会话面板停止后续打开，无法撤销已经提交给浏览器的请求。分组失败不把已打开的标签页算成未打开；重试默认跳过成功项。

## 同步诊断的含义

连接作用域包括后端 URL、表与同步 ID；不包含 anon key。诊断只保存连接的派生标识、操作元数据和脱敏错误，不保存完整 payload 或账户凭据。
操作历史每作用域保留 30 条，最多 8 个作用域；本地空间不可写时保留当前页结果并明确提示。
待上传状态基于当前内容与**最近确认的远端 payload** 的 SHA-256 指纹，不意味着实时探测服务器。
预览读取记录为预览成功，不更新成功同步时间或已确认内容指纹。下载应用/恢复点写入失败不能显示为同步成功。
浏览器配额读取 `storage.sync.getBytesInUse`；Supabase 显示当前快照大小，服务端剩余配额由用户到项目后台查看，界面不虚构数值。

预览会暂停对应后端自动同步，确认前重新核对远端 payload 和本地状态。支持合并、远端替换或取消保留本地；本地替换后不自动上传。
确认替换是整份工作区替换，并非逐字段手动冲突编辑。所有实际覆盖前保留恢复点。
暂停不能撤回已经到达浏览器或服务器的写请求；编辑 Supabase 配置会先暂停自动同步，避免半输入的配置触发请求。

## 权限与隐私

新增 `tabGroups` 仅为可选权限，只有选择读取/恢复分组时申请。会话捕获/恢复在点击时申请 tabs。
书签读取只申请 bookmarks，不修改、删除用户浏览器中的原始书签。文件导入在离线的 inert template 中解析，不执行脚本或插入第三方 HTML。
用户确认导入的书签成为工作区网站，之后会按用户开启的工作区同步设置同步。原始历史、浏览记录和会话不会额外上传。

## 验证

保留已有 65 项场景，新增 `tests/p0-p1.test.js`，使用 Node 内置测试器，不引入运行时/测试框架依赖。
覆盖历史迁移和配额失败、失效预览、移动与删除标记、导入限制/去重、会话权限/隐私/重试、诊断真实性、云同步队列及确认前复核。
云适配器测试执行实际源码，仅替换 Node 不识别的路径别名和 Supabase 传输入口。

```sh
npm run test:unit
npm run build
npm run build:extension
npm run validate:extension
python -m pip install playwright==1.55.0
python -m playwright install chromium
python scripts/smoke-p0p1.py
```

浏览器检查执行真实生产 bundle、React/Radix、localStorage 和跨页 storage 事件；扩展权限/标签页/同步 API 使用测试替身。
截图和报告写入 `qa-output/`，不提交构建产物、字体、临时集成文件或第三方 QA 依赖。
实际测试数量与结果以对应提交的 GitHub Actions 日志为准，不把脚本存在视为验证通过。

## 明确未覆盖

这四项功能不等于数据库 CAS 或分布式一致性方案。跨标签页同时读改写、Supabase 条件更新/RPC、原生同步 generation 内容哈希、时钟偏差和 tombstone 回收仍需独立处理。
没有新增账号认证；共享同步 ID 不是认证机制，用户自有 Supabase 项目仍需正确配置访问控制。
真实 Edge/Chrome 账户双设备同步、原生中文输入法、不同系统浏览器分组权限行为仍应在发布前实机验收。
Node/依赖升级、已有 ESLint 配置缺失和大型 bundle 不在本次功能范围内；不声称全库 lint 或所有仓库工作流都通过。
